# 03 - Multi-Router Labs

## Overview
Full enterprise-scale topology implementations combining multiple routers, switches, firewalls, and end hosts in eNSP.

## Lab Scenarios
- Multi-Branch Enterprise Network with OSPF Backbone
- Hub-and-Spoke Topology with Dynamic Routing
- Dual-Homed Internet Edge with Redundant Default Routes and NAT
- High-Availability Enterprise Campus Core with VRRP and MSTP
