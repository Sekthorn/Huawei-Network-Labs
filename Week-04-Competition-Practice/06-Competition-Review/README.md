# 06 - Competition Review & Strategy

## Overview
Comprehensive review guide, time-management strategies, essential shortcut checklists, and exam day survival tips for the Huawei ICT Competition.

## Strategy Checklist
- Read entire topology requirements thoroughly before applying configurations.
- Allocate time: 20% planning & IP table verification, 50% configuration, 30% verification & testing.
- Always execute `save` on every device before test submission.
- Verify end-to-end ping across all host devices before finishing.
