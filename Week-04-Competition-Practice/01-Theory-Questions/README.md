# 01 - Theory Questions & Concepts

## Overview
Comprehensive set of conceptual and multi-choice questions modelled after the Huawei ICT Competition Preliminary and National Finals.

## Topics Covered
1. VRP CLI & Operating Fundamentals
2. IPv4 / IPv6 Addressing & Subnetting
3. Routing Protocols: Static Routing, OSPF, BGP
4. Switching Technologies: VLANs, Trunks, STP, RSTP, MSTP, Eth-Trunk
5. Network Services & Security: DHCP, ACL, NAT, AAA, IPsec, USG Firewalls
6. WLAN Technologies: CAPWAP, AP discovery, 802.11 standards
