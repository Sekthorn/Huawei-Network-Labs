# 02 - Configuration Challenges

## Overview
Timed speed-run configuration drills designed to build muscle memory on Huawei VRP CLI for competition pressure scenarios.

## Challenge Modules
1. **Speed Setup**: Base router and switch initialization (naming, SSH, management IP) in < 3 minutes.
2. **VLAN & Trunk Drill**: Configuring multi-switch VLAN topologies with Eth-Trunks in < 5 minutes.
3. **OSPF Multi-Area Challenge**: Route convergence and cost tuning in < 7 minutes.
4. **NAT + ACL Security Challenge**: Port forwarding, easy-IP, and security rule lockdown in < 5 minutes.
