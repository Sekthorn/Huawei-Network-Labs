# 07 - Network Segmentation

## Overview
Implement network segmentation strategies using VLANs, subnets, VRFs, and security policies to isolate guest, IoT, and internal enterprise systems.

## Key Principles
- Least privilege access between network segments.
- Traffic containment and minimizing broadcast domains.
- Port isolation (`port-isolate enable`) on Layer 2 switches.
- Inter-zone firewall inspection between tiers.
