# Huawei Network Labs

**Learn. Practice. Understand. Share.**

Welcome to Huawei Network Labs!

This is an open-source educational repository designed to help students learn Huawei networking from fundamentals to advanced practical skills.

The learning materials are organized into a four-week preparation roadmap inspired by the Huawei ICT Competition Practice Track — Network Track.

## Learning Roadmap

- Week 1: Huawei Fundamentals and VRP
- Week 2: Routing and Switching
- Week 3: Network Security and WLAN
- Week 4: Competition Practice and Mock Exams

## What You Will Find

- Simple theoretical explanations
- Huawei VRP CLI commands
- Network topology diagrams
- Huawei eNSP practical labs
- Step-by-step configurations
- Command explanations
- Verification and troubleshooting
- Theory questions and practical exercises
- Lab solutions and learning progress

## Tools

- Huawei eNSP
- Huawei VRP
- Git and GitHub

## Who Can Learn?

- University students
- Networking beginners
- CCNA learners
- Huawei ICT Academy students
- Huawei ICT Competition participants
- Network engineering enthusiasts

## Contribution

Students are welcome to share knowledge, suggest improvements, report errors, and contribute educational materials.

**Let's learn networking together!**
