# 02 - VRP CLI Commands

## Overview
Learn the fundamental command-line interface (CLI) shortcuts, help systems, and essential operational commands on Huawei VRP devices.

## Key Commands
- `system-view` (or `sys`): Enter system view
- `quit` (or `q`): Return to previous view
- `return`: Return directly to user view (Shortcut: `Ctrl + Z`)
- `?`: Context-sensitive help
- `Tab`: Auto-complete commands
- `display current-configuration` (or `dis cur`): View active running configuration
- `display version`: View VRP software version and hardware model
