# 01 - Huawei VRP Introduction

## Overview
Versatile Routing Platform (VRP) is the proprietary operating system used across Huawei network devices including AR series routers and CloudEngine/S-series switches.

## Objectives
- Understand the architecture and features of Huawei VRP.
- Familiarize with device boot sequence and configuration file storage.
- Learn navigation between User View and System View.

## Key Concepts
- **User View (`<Huawei>`)**: Initial mode upon login. Used for viewing device status and running basic display commands.
- **System View (`[Huawei]`)**: Mode accessed via `system-view` used for global device configuration.
- **Interface / Protocol Views**: Specific configuration modes accessed from system view.
