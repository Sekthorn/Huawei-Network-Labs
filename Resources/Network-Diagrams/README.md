# Network Diagrams & Topologies

## Overview
This directory stores network architecture diagrams, eNSP topology snapshots, and visual aids for all lab modules.

## Organization
- `Week-01/`: Topologies for basic VRP and VLAN experiments
- `Week-02/`: Topologies for OSPF, Inter-VLAN routing, and STP
- `Week-03/`: Topologies for Firewalls, NAT, VPN, and WLAN
- `Week-04/`: Comprehensive multi-tier competition topologies
