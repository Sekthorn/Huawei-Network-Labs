## Week 01: Huawei Fundamentals and VRP

- [ ] **01-Huawei-VRP-Introduction**: Huawei VRP overview, operating system basics, navigation modes

## Week 02: Routing and Switching

- [ ] **01-Static-Routing**: Default routes, next-hop vs. outbound interface, floating static routes
- [ ] **02-OSPF**: Single-area OSPF, router ID, network statements, neighbor adjacency verification
- [ ] **03-Inter-VLAN-Routing**: Router-on-a-Stick (sub-interfaces with `dot1q termination vid`), VLANIF interfaces (Layer 3 switches)
- [ ] **04-Link-Aggregation**: Eth-Trunk configuration, manual mode vs. LACP mode, load balancing
- [ ] **05-STP**: Spanning Tree Protocol basics, STP/RSTP/MSTP configuration, root bridge selection, port states
- [ ] **06-Routing-Troubleshooting**: Diagnosing routing table issues, ping/tracert analysis, interface status checks

## Week 03: Security and WLAN

- [ ] **01-ACL**: Basic ACLs (2000-2999), Advanced ACLs (3000-3999), rule ordering, inbound/outbound application

- [ ] **03-NAT**: Easy IP (PAT), NAT Server (port forwarding), static NAT configurations
- [ ] **04-VPN**: GRE tunnels, IPsec VPN fundamentals, tunnel interface configurations
- [ ] **05-WLAN-Architecture**: AC (Access Controller) and AP (Access Point) architecture, CAPWAP tunnel, DHCP setup
- [ ] **06-Wireless-Security**: SSID profile, security profile (WPA2-PSK), VAP profile configuration
- [ ] **07-Network-Segmentation**: Traffic isolation, private VLANs, guest vs. corporate network separation
