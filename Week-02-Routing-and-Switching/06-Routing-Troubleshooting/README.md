# 06 - Routing Troubleshooting

## Overview
Learn systematic methodologies and diagnostic commands to troubleshoot routing issues, protocol neighbor adjacencies, and connectivity failures.

## Key Troubleshooting Tools
- `ping [-a <source-ip>] <target-ip>`
- `tracert <target-ip>`
- `display ip routing-table`
- `display ip interface brief`
- `display ospf error`
- `display ospf peer`
